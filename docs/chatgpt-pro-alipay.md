## 本人账号充值与共享号有什么区别

本人账号充值是把订阅权益开到用户自己的 ChatGPT 账号；共享号、租号或成品号交付的是另一个账号或使用权。需要保留长期聊天记录、代码项目和工作资料时，应优先确认账号控制权，而不是只看标价。

## 支付成功但还没有显示 Pro 怎么办

依次检查：登录账号是否正确 → 登录方式是否一致 → 订单是否已付款 → 是否仍在人工处理 → ChatGPT 页面是否需要刷新或重新登录。先查订单，再联系售后；重复付款不会加快处理。
